================================================================================
  CollMgm - Quick Start Guide
================================================================================

INSTALLATION
------------
1. Double-click  CollMgm-<version>-Setup.exe
2. Click  Next > Next > Finish
   (if asked, keep "Create a desktop shortcut" checked)
3. Setup installs CollMgm as a Windows service and opens it in your browser
   automatically. A "CollMgm" shortcut also appears in the Start Menu and,
   if you kept that checkbox, on your desktop.


LAUNCHING THE APP
------------------
CollMgm runs as a background service, so it's always available at:

    http://localhost:8100

Double-click the "CollMgm" shortcut (Start Menu or desktop) to open that
address in your browser, or type it into any browser's address bar — on
other devices on the same network, use this PC's name or IP address instead
of "localhost".


FIRST-TIME SETUP
-----------------
The very first time anyone opens CollMgm, the login screen offers
"First-time setup? Register the distributor account". That creates the one
distributor login (username, password, and a security question used later
for password recovery). Every other user — supervisors and salesmen — is
then created by the distributor from Manage Users, after signing in.


LOGGING IN
----------
Enter your username and password and click "Sign in". What you see next
depends on your role:

  Distributor  - full access: approves, posts, manages users/beats, and
                 resolves issues other roles raise.
  Supervisor   - approves collection lists and submitted collections.
  Salesman     - generates collection lists for their own beats and
                 submits the payments they collect.


MAIN MENU
---------
The menu only shows what your role can do. The core workflow, in order:

  1. Generate Collection List  - salesman creates today's voucher list
  2. Approve Collection List   - supervisor signs off before it goes out
  3. Submit Collections        - salesman records payments collected
  4. Approve Collections       - supervisor reviews the submitted payments
  5. Post Collections          - distributor writes them into the records

Alongside that: Print Collection List, Correction Requests, Amend Voucher,
Amendment Requests, Checks (payments by check), Import Vouchers / New
Voucher Batches (bringing in a customer's existing vouchers), and Reports.


REPORTS
-------
  - Pending by Salesman / Pending by Beat - what's still outstanding
  - Collection Pipeline    - every collection list, grouped by the stage
                              it's waiting in
  - Onboarding Pipeline    - imported voucher batches, grouped the same way
  - Beats Due              - which beats need a list started today,
                              tomorrow, or are overdue, based on each
                              beat's collection cadence (set in Manage Beats)
  - Oldest Vouchers / Highest Balance / Voucher Search


KNOWN LIMITATIONS
------------------
- Data is stored in a local SQLite database in the install folder
- No undo / rollback once a collection is posted
- Dates default to today's system date
